# docs/ — Index

| Folder | What it is | When to use |
|--------|------------|-------------|
| `report/` | **Submission** — Chapters 1–4 + References + final PDF/TeX. This is what gets submitted. | Viva / TGPT / PDF export |
| `templates/` | **Formatting templates** — `FORMATTING_GUIDE.md` distilled from example PDF pp.21–33 (Table/Fig caption style, Source line, Times 12pt justified). + any `reference.docx` / LaTeX class. | Before exporting `report/` to PDF/DOCX |
| `guides/` | **Reference / how-to** — `PROJECT_GUIDE.md` (plain tour), `COMPLETE_REFERENCE.md` (full tech source of truth), `schema_reference.md` (FlowRecord / ScoredAlert schemas). | Onboarding, viva prep |
| `paper/` | **Research paper material** — `PAPER_OUTLINE.md`, `paper_packaging.md`, `papers_faceoff.md`, `papers_profiles.md`, `exp_plan_gnn_temporal.md`. Numbers vs published papers, outline for publication. | Paper writing, not Semester-7 report |
| `presentations/` | **Slides** — `week3-presentation.html` | Reviews / demos |
| `report/archive/` | **Old versions** — `*_v1_backup.md`, `*_v2.md`, `*_v2.docx`, generator scripts. | History only, not for submission |

**Rules:**
- `report/` is the only folder that gets pushed as the FYP report — keep it clean (6 files + PDF). Old drafts live in `report/archive/`.
- `templates/` is never submitted — it tells you *how* to format `report/`.
- `guides/` + `paper/` are internal reference — not for examiners unless asked.

**Quick links:**
- Start here → `guides/PROJECT_GUIDE.md`
- Full reference → `guides/COMPLETE_REFERENCE.md`
- Build report → `templates/FORMATTING_GUIDE.md` then `report/Chapter1_Introduction.md` … `References.md`
